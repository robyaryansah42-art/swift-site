A fast, dependency-free static site builder that answers exactly as
makefun-site 1.0.0 does — same output tree, byte for byte — but faster:
Markdown is lexed and rendered in one scan, inline spans escape whole plain
runs at once, and slugs are memoised per build.

Run it with Node 22: `node main.ts` reads `/input/cases.json` and writes
`/output/answers.json`. `solve.js` exports `run(input)` for one site.
